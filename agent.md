## Контекст проекта (dak-cali-ai)

Этот файл нужен, чтобы быстро восстановить контекст при импорте репозитория на другом устройстве.

### Коротко о проекте

- **Тематика**: рефрактометрия + обработка цифровых кривых засветки и ML.
- **Две ветки работ**:
  - **Калибровка/регрессия концентрации** (исторический код вокруг `DatasetGenerator.py`, `analysis.py`, `calibration_io.py`, `main.py`).
  - **Бинарная классификация качества кривой** «хорошая/плохая линия» (набор скриптов `BLA_*.py`).

  - **Список источников** оформлен по стилю ГОСТ как в PDF; уточнены библиографические данные для IEEE/MDPI/Nature статей.

  - Есть и «бланк», и короткая формулировка задания.

### BLA_* (классификация good/bad)

- **Назначение**: автоматизировать отбор «пригодных» кривых засветки для подготовки датасета.
- **Признаки**:
  - `k`: максимальный модуль локального наклона \(k = \max_j |y_{j+1}-y_j|\).
  - `accuracy_of_line`: число локальных минимумов («провалов») на сглаженной кривой с порогами.
- **Модель**: `CatBoostClassifier`, в эксперименте использовались авто-веса классов `Balanced`.
- **Тест-пак**: `BLA_test_pack/good` и `BLA_test_pack/bad` (логи).
- **Экспорт из pickle**: `BLA_pkl_to_logs.py` выгружает линии в `.log`.
- **Правило разметки для экспорта** (использовалось в одном из прогонов): good при `k < 140` и провалов `<= 10`, иначе bad.

### Артефакты/данные в репозитории

- `BLA_model.cbm` — сохранённая модель CatBoost (если присутствует).
- `catboost_info/` — служебные файлы обучения CatBoost (логи/таблицы/ивенты).
- В репозитории есть материалы практики (`pract/`, `pract_obzor_refraktometr_ml/`) и PDF/черновики в папке `научно исследовательская практика/`.

### Как быстро запуститься (примерный ориентир)

- Установить зависимости: `pip install -r requirements.txt`
- Исторический запуск: `python main.py`
- Для классификации good/bad: запускать соответствующие скрипты `BLA_cli.py`, `BLA_train.py`, `BLA_eval.py` (параметры — внутри/в конфиге).
