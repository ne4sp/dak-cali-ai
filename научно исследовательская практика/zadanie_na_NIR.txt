Тема работы:
Рефрактометрические измерения и машинное обучение: обзор применений и
бинарная классификация качества кривых засветки (классы «хорошая линия» /
«плохая линия») для подготовки обучающих данных.

Содержание задания:

1. Выполнить обзор литературы и инженерной практики по сочетанию
   рефрактометрии (в том числе цифровой регистрации профиля засветки) с
   методами машинного обучения: классификация, регрессия, обнаружение
   аномалий; привести примеры публикаций по рефрактометрическим и
   близким оптическим измерениям.

2. Изложить физические основы рефрактометрии и типы выходных данных
   цифрового канала (одномерная кривая интенсивности, служебные поля
   сеанса); описать ограничения классической калибровки и типичные
   артефакты кривой засветки.

3. Сформулировать постановку задачи машинного обучения для
   рефрактометрических данных с акцентом на бинарную классификацию
   пригодности кривой для включения в датасет; указать связь со смежной
   задачей оценки концентрации по признакам кривой на очищенных данных.

4. Разработать и программно реализовать модель бинарной классификации:
   извлечение признаков из измерительных записей (в том числе по максимальному
   модулю наклона профиля и по числу локальных провалов на сглаженной
   кривой с заданными порогами); обучение классификатора на основе
   градиентного бустинга (CatBoost) с учётом дисбаланса классов;
   сохранение обученной модели и воспроизводимость параметров.

5. Подготовить тестовые данные (разбиение на обучающую и контрольную
   части, при необходимости — смешанный пакет файлов с разметкой по
   каталогам); провести тестирование, построить матрицу ошибок, оценить
   метрики качества (в том числе точность, F₁, ROC-AUC); проанализировать
   важность признаков и ограничения обобщения.

6. Оформить пояснительную записку (отчёт) по структуре, согласованной с
   кафедрой: введение, вводная часть, основная часть, раздел о тестировании,
   заключение, список использованных источников (оформление по ГОСТ);
   при необходимости — приложения с иллюстрациями и описанием конвейера
   обработки данных.

Результаты работы представить в виде:
— текста научно-исследовательной работы (отчёта);
— программного кода и/или инструкции по воспроизведению эксперимента
  (пути к данным, версии библиотек, параметры модели);
— таблиц и графиков метрик тестирования (по согласованию с руководителем).
